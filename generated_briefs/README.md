# Generated Briefs Directory

This directory contains SEO content briefs generated by the tool.

## Brief Types

- **Markdown Briefs** (`.md`) - Comprehensive SEO content briefs
- **Word Documents** (`.docx`) - Formatted briefs for easy sharing and editing

## Brief Features

- Keyword research and analysis
- SERP competitor analysis
- Domain authority assessment
- Internal linking recommendations
- Live sitemap integration
- Content strategy guidance

## Usage

Briefs are generated by running:
```bash
python scripts/generate_brief.py
```

Or using the enhanced versions:
```bash
python src/updated_simple_seo_brief.py
```

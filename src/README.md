# Source Code Directory

This directory contains the core source code modules for the SEO Content Strategy Tool.

## Core Modules

- `simple_seo_brief.py` - Main SEO brief generation engine
- `content_authority_mapper.py` - Content strategy and topical authority analysis
- `quick_start.py` - Quick start interface for content authority mapping
- `streamlit_app.py` - Web application interface

## Enhanced Modules

- `enhanced_internal_links.py` - Enhanced internal linking analysis
- `live_sitemap_internal_links.py` - Live sitemap integration for internal linking
- `simple_live_sitemap_brief.py` - Simple brief generator with live sitemap
- `updated_simple_seo_brief.py` - Updated brief generator with live sitemap integration
- `improve_brief_generator.py` - Enhanced brief generator with strategic internal linking

## Analysis Modules

- `advanced_analysis.py` - Advanced content analysis features
- `keyword_competitor_analyzer.py` - Keyword and competitor analysis

## Usage

These modules are imported by the main scripts in the `scripts/` directory.

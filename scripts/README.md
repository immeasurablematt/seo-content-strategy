# Scripts Directory

This directory contains the main executable scripts for the SEO Content Strategy Tool.

## Main Scripts

- `generate_brief.py` - Generate individual SEO content briefs
- `run_analysis.py` - Run comprehensive content authority analysis
- `start_web_app.py` - Launch the Streamlit web application

## Batch Processing Scripts

- `batch_enhanced_briefs.py` - Generate multiple enhanced briefs with strategic internal linking
- `batch_live_sitemap_briefs.py` - Generate multiple briefs with live sitemap integration

## Utility Scripts

- `run_brief_with_progress.py` - Run brief generation with progress tracking and error handling

## Usage

Run any script from the project root:
```bash
python scripts/generate_brief.py
python scripts/run_analysis.py
```

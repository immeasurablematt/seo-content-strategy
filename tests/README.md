# Tests Directory

This directory contains test scripts and utilities for validating functionality.

## Test Scripts

- `test_live_sitemap.py` - Test script for live sitemap functionality

## Usage

Run tests to verify functionality:
```bash
python tests/test_live_sitemap.py
```

## Purpose

Test scripts help ensure that:
- API integrations are working correctly
- Data processing functions operate as expected
- New features don't break existing functionality

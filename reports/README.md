# Reports Directory

This directory contains generated analysis reports and data exports.

## Report Types

### Excel Reports
- `ionet_content_strategy_*.xlsx` - Comprehensive Excel reports with multiple sheets:
  - Keywords analysis
  - Cluster summaries
  - Content calendar
  - Content hubs strategy

### JSON Data
- `ionet_data_*.json` - Raw data exports for programmatic use

### Executive Summaries
- `ionet_executive_summary_*.md` - High-level strategic summaries

## File Naming Convention

Files are timestamped with format: `YYYYMMDD_HHMMSS`

## Usage

These reports are generated by running:
```bash
python scripts/run_analysis.py
```

Reports are automatically saved with timestamps to avoid overwriting previous analyses.

# Converters Directory

This directory contains file format conversion utilities.

## Conversion Tools

- `convert_brief_to_docx.py` - Convert markdown briefs to DOCX format
- `convert_to_docx.py` - Quick DOCX converter for any markdown file
- `enhanced_docx_converter.py` - Enhanced DOCX conversion with better formatting

## Usage

Convert any markdown file to DOCX:
```bash
python converters/convert_to_docx.py [filename.md]
```

Or use the enhanced version:
```bash
python converters/enhanced_docx_converter.py
```

## Features

- Preserves markdown formatting
- Handles headers, lists, and links
- Creates professional-looking Word documents
- Maintains document structure and styling
